TOKTOK DOWNLOADER - CARA JALAN DI HP

1. Install Python dan FFmpeg di Termux.
2. Masuk ke folder project.
3. Jalankan:
   pip install -r requirements.txt
4. Jalankan:
   python app.py
5. Buka browser:
   http://127.0.0.1:5000

Catatan:
- Backend memakai yt-dlp.
- Download hanya untuk konten yang memang boleh kamu unduh.
- Untuk audio MP3, FFmpeg harus terpasang.
